Blackbox is a BlackboardChina course-material downloader.

For normal use, install Blackbox from the GitHub Releases page:
1. Windows: run the Blackbox .exe installer.
2. macOS: open the Blackbox .dmg and move it to Applications.
3. Linux: run the Blackbox .AppImage or install the .deb package.

For a source checkout, install Node.js 22.x or 24.x and run start-gui.bat/start-gui.ps1 on Windows or start-gui.sh on macOS/Linux.
