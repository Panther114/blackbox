# Blackbox

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

BlackboardChina users saving course materials locally; operators downloading batches of G-numbers; users exporting course instructions to compatible agent harnesses.

## Product Purpose

A Windows Electron application for discovering courses, selecting files and instructions, and saving them locally. The React renderer also supports an explicitly labeled offline demonstration.

## Operating Context

Downloads, Automation, Agent Skills and Settings are the four existing views. Settings includes credentials, courses, diagnostics and updates. Download stages are preparation, courses, files, transfer and summary.

## Capabilities and Constraints

Preserve current behavior, product copy, saved data, the window.blackboxGui bridge, and data-testid selectors. The minimum desktop viewport is 980 × 680. Bundle imagery, licensed Satoshi and Gambetta fonts and icons locally; request no runtime visual assets. Visual changes belong in the renderer. Packaging must contain the full runtime dependency closure. Windows uses the installed Microsoft Edge; macOS and Linux bundle Playwright Chromium.

## Brand Commitments

Blackbox retains its name and app icon. The user approved a complete visual replacement: centered top navigation, light frosted glass, a misty lake and mountain background, fine lines, cobalt actions, generous spacing and smooth state transitions.

## Product Principles

- Downloads and settings remain clear and usable while visual presentation changes.
- Preserve file selection, cancellation, automation isolation and secure credential behavior.
- Keep data tables legible and keyboard interaction reliable.
- Validate the packaged application, not only source builds.

## Accessibility & Inclusion

Visible keyboard focus, reduced-motion support, accessible labels, readable contrast and bounded desktop layouts.
